# Flywheel Motion Job #2 setup

This directory contains only a minimal, dependency-free static-site build and local preview setup. It intentionally contains no assessment implementation.

Run `npm run build`, then `npm start` and visit `http://127.0.0.1:4173`.

The GitHub Pages workflow is manual-only (`workflow_dispatch`), so it cannot publish until the repository is created, GitHub Pages is configured to use Actions, and someone explicitly runs the workflow.
